# Video test fixture

`flower.mp4` is the short MP4 sample used by the real Electron playback test.

- Source: https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4
- Referenced by: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video
- Format: H.264 video with AAC audio, approximately five seconds long.

The test suite uses the checked-in copy so test runs do not depend on network
availability.
