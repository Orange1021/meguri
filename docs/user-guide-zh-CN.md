# 橙映简体中文使用文档

这是一份面向普通用户的使用说明。橙映是一个本地优先的媒体库：它可以扫描你指定的文件夹，整理视频、图片和音频，生成缩略图，支持搜索、播放、标签和播放列表。媒体文件仍然留在原来的位置，橙映不会替你上传到云端。

> 建议第一次使用时先读完“第一次使用”和“Windows 便携版目录”两节。这样可以避免把程序目录、应用数据和原始媒体混在一起。

## 1. 软件定位

橙映适合个人管理保存在硬盘、移动硬盘或 NAS 映射目录中的视频、图片和音频。主要能力包括：

| 能力           | 用途                                             |
| -------------- | ------------------------------------------------ |
| 工作区         | 为不同的媒体文件夹建立独立入口，快速切换多个库   |
| 增量扫描       | 递归读取文件夹，新增或变化的文件会在扫描后进入库 |
| 网格/列表浏览  | 用缩略图浏览，或按文件夹、大小、日期、评分等查看 |
| 搜索和筛选     | 按文件名、路径、标签、类型、评分、收藏和日期查找 |
| 播放           | 在应用内播放视频和音频，图片可以查看和复制       |
| 元数据         | 维护标签、评分、收藏、场景书签和播放历史         |
| 集合和播放列表 | 手动整理、保存搜索条件、连续播放或导出 M3U8      |
| Discovery      | 从库中随机挑选内容，适合重新发现旧文件           |
| 便携数据       | 程序和个人数据分离，整个目录可以移动到其他盘符   |

橙映的安全边界很简单：它读取你添加的目录，并把数据库、缩略图、封面、日志和备份写入自己的 `Data` 目录。它不会自动修改、移动或删除原始视频、图片和音频。

## 2. Windows 便携版目录

便携版建议保持下面的目录结构：

```text
橙映/
├─ App/                    # 程序文件，升级时替换这一部分
├─ Data/
│  ├─ config.json          # 工作区、集合、应用设置
│  ├─ roots/<工作区ID>/     # 每个工作区的数据库和缩略图
│  ├─ assets/               # 封面、Sheet 等派生资源
│  ├─ playlists/           # 播放列表相关文件
│  ├─ backups/<备份ID>/     # 经过校验的恢复备份
│  ├─ logs/                 # 应用日志
│  └─ temp/                 # 恢复和升级过程中的临时文件
└─ Media/                  # 默认媒体根目录，可在其中放多个子文件夹
```

### 移动到其他盘符

1. 完全退出橙映，确认托盘图标也已经退出。
2. 整个复制 `橙映` 文件夹，不要只复制 `App` 或 `Media`。
3. 在新位置运行 `App` 中的程序。
4. `Media` 下的工作区使用相对位置保存，通常可以随整个目录一起从 `D:` 移到 `E:`。

如果你添加的是 `Media` 之外的文件夹，应用会按绝对路径记录它；换盘符后可能需要重新添加该工作区。

## 3. 第一次使用

### 启动和初始化

1. 双击便携版中的橙映程序（`App/OrangeView.exe`）。如果直接分发单个便携 exe，也可以把它放在根目录并与 `Data`、`Media` 同级运行。
2. 第一次运行如果出现恢复页面，确认显示的 `Data` 目录是当前便携目录中的 `Data`，然后选择“初始化”。不要在不确认目录的情况下删除旧数据。
3. 进入主界面后，点击左侧工作区栏顶部的 `+`，选择一个包含媒体的文件夹。
4. 橙映会递归扫描该文件夹，并在后台生成缩略图。扫描期间可以继续浏览已经发现的文件。
5. 文件夹会被记住，下次启动会自动检查变化。

### 添加新的媒体目录

- 点击左侧的 `+`，或者把文件夹拖到工作区栏。
- 每个目录会成为一个工作区，并拥有自己的索引和缩略图。
- 点击工作区名称可以切换；`All` 可以跨工作区查看全部媒体。
- 从工作区菜单移除只会取消橙映的登记，不会删除硬盘上的文件。

### 新文件没有出现

打开对应工作区后点击顶部的“扫描”。增量扫描会检查新增、修改、移动和改名的文件；如果索引需要完全重建，使用扫描菜单中的重建选项，并等待完成。

## 4. 浏览、搜索和筛选

### 浏览方式

- **网格视图**：适合快速浏览缩略图。
- **列表视图**：适合查看路径、标签、分辨率、时长、大小等信息。
- **文件夹浏览**：点击文件夹进入下一级；播放列表和 Discovery 在按文件夹浏览时会使用该文件夹的整个子树。
- **工作区栏**：在多个媒体目录、`All`、Watch Later 和自建集合之间切换。

### 搜索

主界面顶部的搜索框可以匹配文件名、路径和标签。搜索条件可以组合使用：

- 视频、图片或音频类型；
- 一个或多个标签；
- 最低评分；
- 仅显示收藏；
- 录制/捕获日期和时间；
- 文件名、路径或普通文本。

每个已启用的条件都会显示为一个小标签。点击条件右侧的 `×` 可以只移除这一项；搜索框旁边可以选择排序方式。

> 小技巧：点击缩略图或详情页中的标签，会直接用该标签进行搜索。常用的搜索可以保存为智能集合或智能播放列表。

### 缩放和预览

- 按住 `Ctrl` 滚动鼠标滚轮可以缩放界面。
- `Ctrl` + `+` 放大，`Ctrl` + `-` 缩小，`Ctrl` + `0` 恢复默认大小。
- 视频缩略图支持悬停预览；如果库很大或电脑负载较高，可以在设置中关闭“悬停预览”。

## 5. 播放视频、图片和音频

### 视频和图片

1. 点击缩略图打开详情。
2. 视频会在详情页中播放，支持拖动进度和继续上次的播放位置。
3. 点击详情页中的侧边预览按钮，可以把详情固定在右侧，同时继续查看网格、搜索和底部播放器。
4. 图片会以较大尺寸显示；使用“复制图片”可以复制到剪贴板，再粘贴到聊天、文档或图像工具中。
5. 如果浏览器内置播放不支持某个编码，使用“用外部程序打开”，交给 Windows 默认播放器处理。

### 音频

音频文件会和视频、图片一起进入库。包含内嵌封面时，封面会作为缩略图使用。点击音频后，底部播放器会继续播放，即使你继续搜索、滚动或打开其他详情。

在设置中可以调整音频频谱的开关和样式。播放视频和音频时，橙映会自动避免两个媒体同时发声。

### 播放进度和场景

- 关闭详情或退出播放时，视频的当前位置会被记录。
- 在视频详情中可以把当前时间保存为命名的场景书签，之后直接跳回该位置。
- 图片在连续播放中会停留设定的秒数，也可以在播放设置中调整转场、淡入淡出和轻微移动效果。

## 6. 标签、评分、收藏和历史

这些信息是在橙映的数据库中保存的，不会写进原媒体文件。

- **标签**：在详情页添加自由标签，输入时会提示以前使用过的标签。
- **评分**：用一到五颗星标记内容质量或个人偏好。
- **收藏**：点击心形按钮，把经常回看的内容加入收藏筛选。
- **场景书签**：为视频的具体时间点命名，适合记录精彩片段或参考位置。
- **播放历史**：在历史页面按日期查看播放记录，也能看到最近播放和播放次数。

完成扫描后，应用会尽量依据内容身份跟踪同一文件的改名和移动，因此标签、评分、收藏和历史可以随文件保留。但如果文件内容已经被替换、索引没有完成或文件跨工作区移动，仍应检查结果并保留自己的重要数据备份。

## 7. 集合、稍后观看和播放列表

### 工作区栏中的集合

- **Watch Later（稍后观看）**：内置集合，适合临时保存待看的文件。
- **普通集合**：手动添加文件，可以混合多个工作区，并可设置 Emoji 图标。
- **智能集合**：保存一组搜索条件，每次打开时重新计算结果。

点击左侧集合可以查看其中内容；拖动文件到集合按钮可以加入文件。普通集合可以重命名、改图标、排序或删除，Watch Later 不能被删除。

### 保存的播放列表

顶部播放列表菜单可以创建两种保存列表：

- **静态播放列表**：保存当前列表中的具体文件，适合固定顺序的课程、电影或音乐。
- **智能播放列表**：保存标签等条件，之后会随库内容变化自动更新。

播放列表、当前工作区、文件夹或搜索结果都可以点击播放按钮进入全屏连续播放。播放器支持上一项、下一项、随机播放、重复播放和手动顺序；图片会按设置的停留时间自动进入下一项。

### M3U8 和 PotPlayer

在保存的播放列表菜单中：

1. 选择一个播放列表。
2. 选择“导出 M3U8”，把列表保存为可被其他播放器读取的文件。
3. 如果 Windows 已安装 PotPlayer，可以选择“用 PotPlayer 打开”；应用会生成临时播放列表并交给 PotPlayer。

如果列表中有文件已被删除或无法解析，界面会提示跳过的数量。请先扫描工作区，再重新导出。

### Discovery

点击 Discovery 可以从当前库或文件夹范围内随机挑选内容，全屏查看并通过场景预览快速切换。它适合在不知道具体文件名时重新发现旧媒体。

## 8. 设置与快捷键

打开工作区栏底部的齿轮进入设置。当前中文界面首次启动默认使用简体中文，也可以随时切换为 English、日本語、한국어、Español 或 Français；选择会保存在当前用户配置中。

常用设置包括：

- **界面语言**：切换应用显示语言。
- **主题和明暗外观**：选择主题家族与浅色/深色外观。
- **列表缩略图大小**：调整列表视图中的缩略图。
- **场景缩略图数量和质量**：控制视频详情与预览使用的画面数量。
- **悬停预览**：打开或关闭视频缩略图的悬停取景。
- **播放设置**：设置图片停留时间、转场、淡入淡出、随机播放和继续播放位置。
- **音频频谱**：打开频谱并选择显示样式。
- **应用图标**：当前统一使用橙子圆形 Logo。

常用操作：

| 操作                     | 作用                             |
| ------------------------ | -------------------------------- |
| `Esc`                    | 关闭当前详情或弹层               |
| `Ctrl` + 滚轮            | 缩放界面                         |
| `Ctrl` + `+` / `-` / `0` | 放大、缩小、重置缩放             |
| 播放器中的方向/播放按钮  | 上一项、下一项、暂停和继续       |
| 播放器中按 `I`           | 离开全屏播放器，进入当前文件详情 |
| 详情页场景书签           | 保存或跳转到当前播放时间         |

不同版本或键位预设可能会增加文件翻页、列表焦点和搜索聚焦快捷键；以设置页和当前窗口提示为准。

## 9. 备份、恢复和升级

### 保护数据

应用数据集中在便携目录的 `Data` 下。重要的是定期复制整个 `Data`，并另外备份原始媒体。`Data/backups` 中的备份由应用在迁移或恢复流程中生成，并会经过清单和哈希校验。

### 出现恢复页面时

恢复页面会显示当前数据目录和可用操作：

- **初始化**：确认该目录是新目录且没有要保留的数据时使用。
- **重试**：数据目录暂时被占用、文件尚未准备好或上次操作中断时使用。
- **恢复备份**：只选择列表中校验通过的备份。

排障时不要直接删除 `Data`。先关闭应用，复制整个 `Data` 作为保险，再查看 `Data/logs/main.log` 中的日志或恢复页面给出的具体路径。

### 便携版升级和回滚

如果采用目录式便携升级，把新程序放在 `App.new`，关闭应用后执行：

```powershell
node scripts/portable-upgrade.mjs --root D:\PortableVideoLibrary --activate
```

程序会保留旧版本到 `App.previous`，不会主动改动 `Data` 和 `Media`。如果新程序无法启动，可以回滚：

```powershell
node scripts/portable-upgrade.mjs --root D:\PortableVideoLibrary --rollback
```

升级前后的数据库迁移会先创建备份。任何升级操作都建议保留一份你自己的 `Data` 备份。

## 10. 常见问题

### 添加文件夹后没有内容

确认选择的是文件夹而不是单个文件，等待扫描完成，然后点击顶部“扫描”。检查文件扩展名是否为应用支持的媒体类型，并确认文件夹仍然存在。

### 我移动或改名了文件，标签还在吗？

在同一工作区内，完成下一次扫描后，应用会尝试依据内容身份保留标签、评分、收藏和历史。内容被替换或扫描失败时不要假设一定能恢复，先检查详情页。

### 缩略图为空或生成很慢

视频缩略图需要读取媒体并由内置工具生成。可以先继续浏览，稍后等待后台任务完成；检查 `Data/logs/main.log` 获取具体错误。设置 → 应用 → 诊断日志可以直接打开日志目录。扫描失败提示会同时显示简要原因和完整日志位置；数据库中的 `scan_runs`、`scan_issues` 还会保留每次扫描及单文件问题。删除原文件旁边的任何文件不会修复应用自己的缩略图缓存，应该先重新扫描。

### 视频无法在应用内播放

打开详情后选择“用外部程序打开”。这不会复制或修改原视频，只会让 Windows 默认播放器尝试打开它。

### 关闭窗口后应用没有退出

橙映默认把窗口隐藏到系统托盘，以便扫描和播放器继续工作。双击托盘图标可以重新打开；需要真正退出时，在托盘菜单中选择退出。

### 如何彻底卸载？

先按系统方式卸载程序。如果还要删除标签、历史、缩略图、设置和备份，再单独处理橙映的 `Data` 目录。原始媒体位于你添加的工作区或 `Media` 中，不会因为卸载程序自动删除。

### 我的数据会上传吗？

不会。橙映的媒体库、标签、搜索和播放历史都在本机；应用只通过本机地址向自己的窗口提供媒体流，不把这些内容发送到外部服务器。若使用“用外部程序打开”，文件会按照你选择的 Windows 程序行为处理。
